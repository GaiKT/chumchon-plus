## สิ่งที่ต้องทำ

admin เพิ่มบุคคลหรือครัวเรือนใหม่ได้ และบันทึกเมื่อมีคนย้ายออกหรือเสียชีวิตโดยไม่ต้องลบข้อมูล

- ปุ่มเพิ่มครัวเรือนใหม่ (บ้านเลขที่ต้องไม่ซ้ำในหมู่บ้าน)
- ปุ่มเพิ่มสมาชิกในหน้าครัวเรือน
- เปลี่ยน status ของบุคคลเป็น อาศัยอยู่ / ย้ายออก / เสียชีวิต
- ถ้าหัวหน้าครัวเรือนถูกเปลี่ยนเป็นย้ายออกหรือเสียชีวิต ให้ระบบแจ้งเตือนและให้เลือกหัวหน้าครัวเรือนคนใหม่จากสมาชิกที่อาศัยอยู่
- ตัวเลือก "รวมผู้ที่ย้ายออก/เสียชีวิต" ในหน้าค้นหา (ค่าเริ่มต้นปิด)
- ทุกการเพิ่มและเปลี่ยน status บันทึกลง audit log ตาม #09

## เกณฑ์ตรวจรับ

- [ ] เพิ่มครัวเรือนที่บ้านเลขที่ซ้ำไม่ได้ และมีข้อความแจ้ง
- [ ] เพิ่มสมาชิกแล้วค้นหาพบทันที
- [ ] เปลี่ยน status หัวหน้าครัวเรือนแล้วระบบให้เลือกหัวหน้าคนใหม่
- [ ] ผู้ที่ย้ายออกหรือเสียชีวิตไม่แสดงในผลค้นหา จนกว่าจะเปิดตัวเลือก "รวมผู้ที่ย้ายออก/เสียชีวิต"
- [ ] มีแถวใน audit log ทุกครั้งที่เพิ่มหรือเปลี่ยน status

## ที่มา

ใช้ในการประชุมหมู่บ้าน และเป็นแผนสำรองตอนเกิดภัย (น้ำท่วม ไฟดับ ไม่มีสัญญาณ) เพราะแอปใช้ได้เฉพาะออนไลน์ ระบบไม่เก็บข้อมูลไว้ในเครื่อง (ตัดสินใจไว้ใน v1)

## สิ่งที่ต้องทำ

- ปุ่ม "พิมพ์" ในหน้ารายชื่อ (#20) และหน้าความเปลี่ยนแปลง (#21) เรียก `window.print()`
- print stylesheet: ซ่อนแถบบน เมนู ปุ่ม และช่องค้นหา แสดงเป็นตาราง ตัวอักษร 12pt ขาวดำ
- หัวกระดาษ: ชื่อหมู่บ้าน หมู่ที่ ตำบล เงื่อนไขที่กรอง วันที่พิมพ์ (พ.ศ.) และชื่อผู้พิมพ์
- ท้ายกระดาษ: "เอกสารนี้มีข้อมูลส่วนบุคคล ห้ามเผยแพร่" เลขหน้า
- บันทึกลง audit log ว่าใครพิมพ์รายการอะไร เมื่อไร (การพิมพ์คือการนำข้อมูลออกจากระบบ)
- ไม่สร้างไฟล์ PDF หรือ CSV บน server

## เกณฑ์ตรวจรับ

- [ ] print preview ไม่มีปุ่มหรือเมนูติดมา
- [ ] หัวกระดาษมีเงื่อนไขที่กรองครบ
- [ ] มีแถวใน audit log ทุกครั้งที่กดพิมพ์
- [ ] รายชื่อ 100 คนพิมพ์ได้ไม่เกิน 4 หน้า A4

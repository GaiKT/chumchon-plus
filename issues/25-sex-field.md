## ที่มา

รายงานจำนวนประชากรของอำเภอแยกชาย/หญิง ตอนนี้ระบบไม่เก็บเพศ เดาได้จากคำนำหน้าเท่านั้น และบางคนไม่มีคำนำหน้า

## สิ่งที่ต้องทำ

- migration เพิ่ม `sex` enum (`male`, `female`) nullable
- เติมค่าข้อมูลเดิมจากคำนำหน้า: นาย, ด.ช., เด็กชาย → ชาย / นาง, นางสาว, น.ส., ด.ญ., เด็กหญิง → หญิง ที่เหลือเว้นว่าง
- ฟอร์มบุคคล: select "เพศ" (ชาย / หญิง / ไม่ระบุ) เลือกให้อัตโนมัติเมื่อกรอกคำนำหน้าที่รู้เพศ แต่แก้ได้
- CSV import (`seed:residents`) รับคอลัมน์ "เพศ" ถ้ามี ถ้าไม่มีให้เดาจากคำนำหน้าแบบเดียวกัน
- แสดงในหน้าสรุป (#23) และเป็นตัวกรองในหน้ารายชื่อ (#20)
- ไม่แสดงเพศในการ์ดผลค้นหา (ไม่จำเป็นต่องานค้นหา)

## เกณฑ์ตรวจรับ

- [ ] migration เติมค่าจากคำนำหน้าถูกต้อง (unit test ทุกคำนำหน้าใน `search-query.ts`)
- [ ] เลือก "นาง" ในคำนำหน้าแล้วช่องเพศเป็นหญิง แต่เปลี่ยนเองได้
- [ ] การเปลี่ยนเพศบันทึกลง audit log

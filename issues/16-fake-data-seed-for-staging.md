## สิ่งที่ต้องทำ

หมู่บ้านทดลองมีเพียง 30 คน ซึ่งไม่พอทดสอบหน้าผลค้นหาเมื่อมีผลลัพธ์จำนวนมากหรือชื่อซ้ำ จึงต้องมีข้อมูลปลอมไว้ทดสอบบน staging

- script สร้างข้อมูลปลอมประมาณ 150 ครัวเรือน 500 คน ในหมู่บ้านทดสอบแยกต่างหาก
- ชื่อ นามสกุล และชื่อเล่นภาษาไทยที่ดูสมจริง มีชื่อซ้ำและชื่อคล้ายกันปนอยู่ (เช่น สมชาย/สมชาญ)
- บ้านเลขที่หลายรูปแบบ เช่น `12`, `12/1`, `123`
- มีผู้ที่ย้ายออก ผู้ที่เสียชีวิต และบ้านว่างปนอยู่
- ใช้ seed script และ Zod schema เดียวกับ #01
- script ต้องปฏิเสธการรันเมื่อเชื่อมต่อกับฐานข้อมูล production

## เกณฑ์ตรวจรับ

- [ ] รัน script แล้วได้ข้อมูลประมาณ 500 คนในหมู่บ้านทดสอบ
- [ ] มีชื่อซ้ำ ชื่อคล้าย และ status หลากหลาย
- [ ] script ปฏิเสธการรันกับ production

## สิ่งที่ต้องทำ

ข้อมูลต้องไม่หายแม้ home server เสีย และต้องรู้ทันทีเมื่อระบบใช้งานไม่ได้

**ส่วนที่ทำโดย agent:**
- job รัน `pg_dump` ทุกคืน แล้วเข้ารหัสด้วย `age` หรือ `gpg` ก่อนส่งออกนอก server (Google Drive ของบัญชีกลาง หรือ Cloudflare R2)
- เก็บ backup ย้อนหลังอย่างน้อย 30 วัน และลบไฟล์ที่เก่ากว่านั้น
- script restore จากไฟล์ backup ลงฐานข้อมูลใหม่
- endpoint health check ที่ไม่เปิดเผยข้อมูลใดๆ
- เอกสารขั้นตอน restore

**ส่วนที่ต้องทำโดยคน (HITL):**
- สร้าง key สำหรับเข้ารหัส และเก็บ private key ไว้นอก server อย่างน้อย 2 ที่ ถ้า key หาย backup จะใช้ไม่ได้
- ใส่ credentials ของที่เก็บ backup
- **ซ้อม restore จริง 1 ครั้งก่อนเริ่ม pilot** โดย restore ลง staging แล้วตรวจว่าข้อมูลครบ
- ตั้ง uptime monitor (เช่น UptimeRobot หรือ healthchecks.io) ให้แจ้งเตือนเข้า LINE หรือ email
- ต่อ UPS ให้ server
- แจ้งผู้ใหญ่บ้านว่าถ้าระบบล่มให้ใช้สมุดไปก่อน

## เกณฑ์ตรวจรับ

- [ ] มีไฟล์ backup ที่เข้ารหัสแล้วนอก server ทุกวัน
- [ ] ไฟล์ backup เปิดอ่านไม่ได้ถ้าไม่มี key
- [ ] ซ้อม restore สำเร็จ และข้อมูลครบ
- [ ] ปิด server แล้วได้รับการแจ้งเตือนภายใน 5 นาที
- [ ] health check ไม่คืนข้อมูลส่วนบุคคล

## สิ่งที่ต้องทำ

ป้องกันไม่ให้ข้อมูลของหมู่บ้านหนึ่งรั่วไปให้อีกหมู่บ้านเห็น ซึ่งถือเป็นการละเมิด PDPA โดยมีชุดทดสอบอัตโนมัติที่รันทุกครั้งก่อน deploy

- fixture ทดสอบที่มี 2 หมู่บ้าน (A และ B) พร้อมผู้ใช้และข้อมูลลูกบ้านของแต่ละหมู่บ้าน
- Playwright test ที่ผู้ใช้หมู่บ้าน A:
  - เปิด URL ของครัวเรือนหรือบุคคลในหมู่บ้าน B โดยตรง ต้องได้ 404
  - ค้นหาชื่อที่มีเฉพาะในหมู่บ้าน B ต้องไม่พบผลลัพธ์
- test ระดับฐานข้อมูลว่า query ที่ตั้ง `app.village_id` เป็นหมู่บ้าน A จะไม่คืนแถวของหมู่บ้าน B แม้ไม่ได้ใส่เงื่อนไข `village_id` ใน query
- ตั้ง CI ให้รัน test ชุดนี้ และ deploy ไม่ได้ถ้า test ไม่ผ่าน
- เพิ่ม test ทำนองเดียวกันทุกครั้งที่มีหน้าใหม่ที่แสดงหรือแก้ไขข้อมูลลูกบ้าน (ระบุไว้ในเกณฑ์ตรวจรับของ issue ที่เกี่ยวข้อง)

## ที่มา

เมื่อเกิดภัยหรือเหตุฉุกเฉิน ผู้ใหญ่บ้านต้องระดมคนช่วยและช่วยผู้ประสบภัย (ม.27) ต้องบอกทางให้รถพยาบาลหรือทีมช่วยเหลือ ผู้ช่วยที่เพิ่งเข้ามาทำงานก็ยังไม่รู้ว่าบ้านเลขที่ไหนอยู่ตรงไหน

## สิ่งที่ต้องทำ

- migration เพิ่ม `latitude`, `longitude` (nullable) ในตาราง `households`
- ฟอร์มบ้าน: ปุ่ม "ใช้ตำแหน่งปัจจุบัน" (ใช้ตอนยืนอยู่หน้าบ้าน) และช่องวางลิงก์ Google Maps ที่ระบบแยกพิกัดออกมาให้
- หน้าครัวเรือน: ปุ่ม "เปิดแผนที่" ไปที่ Google Maps (`https://www.google.com/maps/search/?api=1&query=lat,lng`) และปุ่ม "คัดลอกตำแหน่ง" สำหรับส่งใน LINE
- ไม่ฝังแผนที่ในแอป (ไม่โหลด script ภายนอก ตาม CSP และเร็วบน 3G)
- แก้ `Permissions-Policy` ใน `next.config.ts` จาก `geolocation=()` เป็น `geolocation=(self)`
- เปลี่ยนตำแหน่งบันทึกลง audit log

## เกณฑ์ตรวจรับ

- [ ] วางลิงก์ Google Maps ทั้งแบบยาวและแบบสั้น (`maps.app.goo.gl`) แล้วได้พิกัด หรือมีข้อความบอกว่าใช้ไม่ได้
- [ ] ปุ่ม "ใช้ตำแหน่งปัจจุบัน" ขออนุญาตก่อน และถ้าผู้ใช้ปฏิเสธมีข้อความบอกวิธีอื่น
- [ ] บ้านที่ไม่มีพิกัดไม่แสดงปุ่ม "เปิดแผนที่"
- [ ] security header test อัปเดตตาม Permissions-Policy ใหม่

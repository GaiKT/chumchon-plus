## สิ่งที่ต้องทำ

admin ลบรายการที่กรอกผิดหรือซ้ำได้ แต่กู้คืนได้ถ้าลบผิด ใช้กับข้อมูลที่ผิดเท่านั้น กรณีย้ายออกหรือเสียชีวิตให้ใช้การเปลี่ยน status ตาม #10

- ปุ่มลบที่บุคคลและครัวเรือน ต้องยืนยัน 2 ชั้น ชั้นที่ 2 ให้พิมพ์ชื่อหรือบ้านเลขที่เพื่อยืนยัน
- ลบแบบ soft delete โดยตั้งค่า `deleted_at` รายการที่ถูกลบไม่แสดงในทุกหน้า
- ลบครัวเรือนที่ยังมีสมาชิกอาศัยอยู่ไม่ได้ ต้องย้ายหรือลบสมาชิกก่อน
- หน้า "รายการที่ถูกลบ" แสดงรายการที่ลบภายใน 30 วัน พร้อมปุ่มกู้คืน
- job ที่ลบถาวรเมื่อเกิน 30 วัน ใช้ cron ของระบบหรือ container แยก ห้ามใช้บริการที่ผูกกับผู้ให้บริการ hosting
- การลบและการกู้คืนบันทึกลง audit log

## เกณฑ์ตรวจรับ

- [x] ลบแล้วรายการหายจากผลค้นหาและหน้ารายละเอียด
- [x] กู้คืนภายใน 30 วันได้ และข้อมูลกลับมาครบ
- [x] ลบครัวเรือนที่ยังมีสมาชิกอาศัยอยู่ไม่ได้
- [x] job ลบถาวรลบเฉพาะรายการที่เกิน 30 วัน (`pnpm purge:deleted` ให้ตั้ง cron บน server ใน #17)
- [x] มีแถวใน audit log ทุกครั้งที่ลบหรือกู้คืน

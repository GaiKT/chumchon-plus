## สิ่งที่ต้องทำ

ถ้ามือถือหายหรือถูกยืมไป admin ยกเลิกการเข้าสู่ระบบของอุปกรณ์นั้นได้ทันที

- หน้า "อุปกรณ์ที่เข้าสู่ระบบ" แสดงรายการ session ของผู้ใช้ทุกคนในหมู่บ้าน: ชื่อผู้ใช้, ประเภทอุปกรณ์/browser, เวลาใช้งานล่าสุด
- ปุ่มยกเลิก session ทีละรายการ และปุ่มยกเลิกทั้งหมดของผู้ใช้คนหนึ่ง
- ปุ่มปิดการใช้งานบัญชีผู้ใช้ เมื่อกดแล้วยกเลิกทุก session ของบัญชีนั้นด้วย
- ยกเลิกแล้วมีผลกับ request ถัดไปทันที
- การยกเลิกและการปิดบัญชีบันทึกลง audit log

## เกณฑ์ตรวจรับ

- [ ] ยกเลิก session แล้วอุปกรณ์นั้นถูกพาไปหน้าเข้าสู่ระบบใน request ถัดไป
- [ ] บัญชีที่ถูกปิดใช้งานเข้าสู่ระบบใหม่ไม่ได้ ทั้งด้วยรหัสผ่านและ LINE
- [ ] เห็นเฉพาะ session ของผู้ใช้ในหมู่บ้านตนเอง

## สิ่งที่ต้องทำ

ผู้ใช้พิมพ์ชื่อ นามสกุล หรือชื่อเล่นในช่องค้นหาช่องเดียว แล้วเห็นรายการลูกบ้านที่ตรงกันทันทีบนมือถือ

- ช่องค้นหาช่องเดียวอยู่บนสุดของหน้าแรกหลังเข้าสู่ระบบ
- ค้นหาแบบ substring ใน ชื่อ + นามสกุล + ชื่อเล่น โดยค้นที่ฝั่ง server
- ตัดคำนำหน้า (นาย นาง นางสาว ด.ช. ด.ญ. ฯลฯ) ออกจากคำค้นก่อนค้นหา เช่น "นายสมชาย" กับ "สมชาย" ต้องได้ผลเหมือนกัน
- เริ่มค้นหาเมื่อพิมพ์ครบ 2 ตัวอักษร และหน่วง (debounce) ประมาณ 300ms
- แสดงผลไม่เกิน 20 รายการ
- การ์ดผลลัพธ์แสดง: ชื่อ-นามสกุล (ชื่อเล่น), บ้านเลขที่, อายุ (คำนวณจากวันเกิด)
- ค่าเริ่มต้นแสดงเฉพาะผู้ที่มี status อาศัยอยู่ และไม่แสดงรายการที่ถูกลบ
- มีข้อความแจ้งเมื่อไม่พบผลลัพธ์
- server ส่งกลับเฉพาะ field ที่ต้องแสดงบนการ์ด

## สิ่งที่ต้องทำ

admin แก้ไขข้อมูลบุคคลหรือครัวเรือนได้จากหน้ารายละเอียด และระบบบันทึกทุกการเปลี่ยนแปลงไว้ตรวจสอบย้อนหลัง

- ปุ่มแก้ไขในหน้ารายละเอียดครัวเรือน (แก้ข้อมูลครัวเรือน) และที่สมาชิกแต่ละคน (แก้ข้อมูลบุคคล)
- ฟอร์มใช้ Zod schema เดียวกับ #01 แสดงข้อความ error เป็นภาษาไทยแบบทางการ
- ย้ายบุคคลไปครัวเรือนอื่นในหมู่บ้านเดียวกันได้ ด้วยการเลือกครัวเรือนใหม่
- ตาราง `audit_logs` (มี `village_id` และ RLS เหมือนตารางอื่น) บันทึก: ผู้แก้, เวลา, ตารางและ record, ค่าเก่า → ค่าใหม่ เฉพาะ field ที่เปลี่ยน
- บันทึก audit log ใน transaction เดียวกับการแก้ไข
- v1 ไม่ต้องมีหน้าจอดู audit log

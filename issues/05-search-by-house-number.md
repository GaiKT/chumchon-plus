## สิ่งที่ต้องทำ

เมื่อผู้ใช้พิมพ์คำค้นที่ขึ้นต้นด้วยตัวเลข ระบบค้นหาตามบ้านเลขที่แทนการค้นหาตามชื่อ โดยใช้ช่องค้นหาช่องเดิม ไม่ต้องเลือกโหมด

- คำค้นที่ขึ้นต้นด้วยตัวเลขให้ค้นแบบ prefix ในบ้านเลขที่ เช่น `12` พบ `12`, `12/1`, `123`
- เรียงลำดับให้บ้านเลขที่ที่ตรงพอดีขึ้นก่อน
- แสดงผลด้วยการ์ดแบบเดียวกับ #04
- เริ่มค้นหาได้ตั้งแต่ตัวเลข 1 ตัว (บ้านเลขที่สั้น)

## เกณฑ์ตรวจรับ

- [x] พิมพ์ `12` แล้วพบบ้าน `12`, `12/1`, `123` และ `12` อยู่ลำดับแรก
- [x] พิมพ์ `12/1` แล้วพบเฉพาะบ้านที่ขึ้นต้นด้วย `12/1`
- [x] พิมพ์ตัวอักษรยังค้นหาตามชื่อเหมือนเดิม

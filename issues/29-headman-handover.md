## ที่มา

ผู้ใหญ่บ้านพ้นตำแหน่งได้หลายทาง (ครบวาระ อายุครบ 60 ปี ลาออก ถูกให้ออก) และผู้ช่วยผู้ใหญ่บ้านต้องพ้นตำแหน่งตามไปด้วย ระบบยังไม่มีขั้นตอนว่าข้อมูลหมู่บ้านจะไปอยู่กับใคร

## ต้องตัดสินใจ (ควรตกลงก่อนเริ่ม pilot)

- [ ] ใครเป็น **ผู้ควบคุมข้อมูลส่วนบุคคล** ตาม PDPA: ตัวผู้ใหญ่บ้าน, ที่ทำการผู้ใหญ่บ้าน, หรือผู้ให้บริการระบบ ต้องเขียนในประกาศความเป็นส่วนตัว (#19)
- [ ] เมื่อผู้ใหญ่บ้านพ้นตำแหน่ง: ปิดบัญชีทันที (ใช้ "ปิดการใช้งานบัญชี" ใน #13) แล้วสร้างบัญชีให้คนใหม่ หรือรอคนใหม่มารับ
- [ ] ระหว่างที่ยังไม่มีผู้ใหญ่บ้านคนใหม่ ใครดูแลข้อมูล (ผู้ช่วยที่รักษาการแทน)
- [ ] ผู้ใหญ่บ้านคนเก่าขอสำเนาข้อมูลออกไปได้หรือไม่
- [ ] ถ้าหมู่บ้านเลิกใช้ระบบ: ส่งข้อมูลคืนในรูปแบบใด แล้วลบภายในกี่วัน

## สิ่งที่ต้องทำหลังตัดสินใจ

- เขียนขั้นตอนไว้ใน README (ส่วน runbook) และประกาศความเป็นส่วนตัว
- ถ้าต้องมีการส่งออกข้อมูลทั้งหมู่บ้าน ทำ CLI สำหรับ superadmin (ไม่ทำเป็นปุ่มในแอป)

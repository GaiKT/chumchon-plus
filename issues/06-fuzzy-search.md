## สิ่งที่ต้องทำ

ผู้ใช้พิมพ์ชื่อผิดเล็กน้อย (เช่น ณ/น หรือสระสลับ) แล้วยังพบคนที่ต้องการ

- ใช้ `pg_trgm` similarity กับชื่อ นามสกุล และชื่อเล่น ร่วมกับการค้นหาแบบ substring เดิม
- เรียงลำดับผล: ตรงพอดี > ขึ้นต้นด้วยคำค้น > substring > คล้ายกัน (similarity)
- สร้าง trigram index ที่ field ที่ใช้ค้นหา
- กำหนดค่า similarity threshold ไว้ใน config ที่เดียว เพื่อปรับได้ภายหลัง

## เกณฑ์ตรวจรับ

- [ ] พิมพ์ "สมชาญ" แล้วยังพบ "สมชาย"
- [ ] ผลที่ตรงพอดีอยู่ลำดับแรกเสมอ
- [ ] ค้นหาบนข้อมูลทดสอบ 500 คน (#16) ตอบกลับภายใน 300ms ที่ฝั่ง server

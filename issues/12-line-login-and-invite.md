## สิ่งที่ต้องทำ

ผู้ช่วยผู้ใหญ่บ้านเข้าสู่ระบบด้วยบัญชี LINE ได้โดยไม่ต้องจำรหัสผ่าน และเฉพาะคนที่ได้รับเชิญเท่านั้นที่เข้าได้

**ส่วนที่ต้องทำโดยคน (HITL):**
- สร้าง LINE Login channel ใน LINE Developers ด้วยบัญชีกลางของหมู่บ้าน (ห้ามใช้บัญชีส่วนตัว)
- ตั้ง callback URL ด้วย domain ของ production จาก #17
- นำ channel ID และ secret ใส่ใน env ของ server

**ส่วนที่ทำโดย agent:**
- เพิ่ม LINE provider ใน Better Auth ให้ตรวจก่อนว่าเวอร์ชันที่ใช้มี LINE provider ในตัว ถ้าไม่มีให้ใช้ generic OAuth plugin
- admin สร้างลิงก์เชิญได้จากหน้าจัดการผู้ใช้
  - ใช้ได้ครั้งเดียว หมดอายุใน 48 ชั่วโมง
  - ผูกกับหมู่บ้านของ admin ที่สร้าง
- ผู้ได้รับเชิญกดลิงก์ แล้วเข้าสู่ระบบด้วย LINE ระบบผูก LINE user ID กับบัญชีใหม่ในหมู่บ้านนั้น
- คนที่เข้าสู่ระบบด้วย LINE แต่ไม่มีบัญชีในระบบ ถูกปฏิเสธพร้อมข้อความ "ไม่มีสิทธิ์เข้าใช้งาน กรุณาติดต่อผู้ใหญ่บ้าน"
- รหัสผ่านจาก #02 ยังใช้ได้ เป็นช่องทางสำรองเมื่อ LINE ใช้งานไม่ได้

## เกณฑ์ตรวจรับ

- [ ] ผู้ได้รับเชิญเข้าสู่ระบบด้วย LINE ได้ และเห็นข้อมูลหมู่บ้านที่ถูกต้อง
- [ ] ลิงก์เชิญใช้ซ้ำไม่ได้ และใช้ไม่ได้หลัง 48 ชั่วโมง
- [ ] บัญชี LINE ที่ไม่ได้รับเชิญถูกปฏิเสธ
- [ ] ผู้ใหญ่บ้านยังเข้าสู่ระบบด้วยรหัสผ่านได้
- [ ] บัญชีและ channel ของ LINE อยู่ภายใต้บัญชีกลางของหมู่บ้าน

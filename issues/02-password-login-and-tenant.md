## สิ่งที่ต้องทำ

ผู้ใช้เข้าสู่ระบบด้วยรหัสผ่านได้ และระบบรู้ว่าผู้ใช้อยู่หมู่บ้านไหนจาก session แทนการรับค่าจาก env

- ใช้ Better Auth + Drizzle adapter เก็บ session ในฐานข้อมูล อายุ 30 วันแบบต่ออายุอัตโนมัติเมื่อใช้งาน (sliding)
- ตาราง `users` มี `village_id` และ `role` (`admin` / `superadmin`)
- ทุกหน้าที่มีข้อมูลลูกบ้านต้องเข้าสู่ระบบก่อน ถ้ายังไม่เข้าสู่ระบบให้ redirect ไปหน้าเข้าสู่ระบบ
- helper จาก #01 อ่าน `village_id` จาก session แทน env
- `superadmin` ไม่มี `village_id` และไม่เห็นข้อมูลลูกบ้านผ่านหน้าจอปกติ
- CLI สำหรับ superadmin:
  - สร้างหมู่บ้านใหม่
  - สร้างบัญชี admin คนแรกของหมู่บ้านพร้อมรหัสผ่านเริ่มต้น
- ปุ่มออกจากระบบ
- หน้าจอทั้งหมดเป็นภาษาไทยแบบทางการ

## เกณฑ์ตรวจรับ

- [ ] ผู้ที่ยังไม่เข้าสู่ระบบเปิดหน้ารายชื่อแล้วถูกพาไปหน้าเข้าสู่ระบบ
- [ ] admin เข้าสู่ระบบแล้วเห็นเฉพาะข้อมูลหมู่บ้านของตนเอง
- [ ] superadmin เข้าสู่ระบบแล้วไม่เห็นข้อมูลลูกบ้าน
- [ ] CLI สร้างหมู่บ้านและ admin คนแรกได้
- [ ] ออกจากระบบแล้ว session ถูกลบออกจากฐานข้อมูล
